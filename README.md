# F1 Timeline

Неофициальная аналитика Формулы-1: календарь, турнирная таблица, пилоты, команды, трассы и история чемпионатов.

**Сайт:** https://oswarit.github.io/f1-timeline/

Данные берутся из открытых источников: [Jolpica F1](https://github.com/jolpica/jolpica-f1), [OpenF1](https://openf1.org),
[Open-Meteo](https://open-meteo.com) и Википедия. Авторы и лицензии фотографий указаны на сайте.
Проект не связан с Formula 1, FIA и командами.

## Как установить на iPhone

1. Откройте https://oswarit.github.io/f1-timeline/ в **Safari**.
2. Нажмите кнопку «Поделиться» (квадрат со стрелкой вверх).
3. Выберите «На экран „Домой“» и нажмите «Добавить».

Сайт появится на экране как приложение со своей иконкой и будет открываться без адресной строки.
Последние загруженные данные доступны и без интернета.

На Android: откройте сайт в Chrome, меню «⋮» → «Установить приложение».
